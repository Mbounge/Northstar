# Northstar Phase 3.6 — First Design Guarantee

Phase 3.6 closes the zero-transformation settlement path exposed after Phase 3.5.

## Runtime guarantees

- Premium-plan metadata is normalized into a provisional browser-auditable contract instead of rejecting otherwise executable HTML, CSS, SVG, and JavaScript before dispatch.
- Missing thesis, evidence, resolution, structural-analysis, novelty, and publication metadata is repaired deterministically. The mounted browser still decides whether those obligations are visibly realized.
- Repairs preserve a run-specific diversity anchor. They do not choose a visual template or replace the model-authored source.
- A run that requires an artboard cannot settle as completed or completed-with-notes until the mounted browser has accepted at least one material model-authored creative act.
- Stopping a failed continuation is distinct from publication readiness. An accepted artboard may settle with notes after later optional refinement fails, but the deterministic evidence scaffold may not.

## Why this preserves quality

Normalization permits the first safe visual source to become visible; it does not mark the artifact premium. The browser audit, rendered critique, independent review, and publication checks remain responsible for quality. Missing repaired obligations remain visible blockers that drive another model-authored revision.

## Diagnostics

The trace now records:

- premium-contract repair count and exact repairs;
- `creative.completion.blocked` when terminal settlement reaches publication without material creative authorship;
- the accepted creative-act count and exact reason terminal settlement was denied.
