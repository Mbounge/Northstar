## Review decisions before a baseline

1. Two people independently assess the proposed calibration excerpts using their stated checkpoints, then compare disagreements. An excerpt with no expected failure is not a full passing submission. Record actual reviewers and outcomes; do not synthesize signatures.
2. Agree that these four development questions and their acceptance criteria are useful. Record the author and independent human approvals against the exact printed review digests when complete. Preserve the draft state until then.
3. Perform a zero-credit application preflight on `/canvas`: import the supplied MP4s/GIFs through the media control, confirm playback/seeking, select/move/edit/undo individual objects, and save/reopen the same board. Test PNG/JPG and text/CSV delivery through supported attachment paths. A format the app cannot accept is an environment gap to resolve before scoring, not permission to rewrite the input silently.
4. Record which evidence tools Northstar actually has. Media playback does not imply model visual access. Test access to supplied stills, inspectable GIF states, source pages and event files. If a required observation or usage receipt cannot be captured, mark that gap rather than manufacture it.
5. Agree on a pinned app/model/tool configuration and budget, then separately authorize the first live collection. Use this unchanged version for the initial baseline and later paired comparisons. Retain first renders, failures, repairs and costs.

The first run may be an explicitly labelled draft calibration rehearsal if desired. It cannot be reported as a certified benchmark result. Independent discovery certification remains false for all open-web cases. No public ranking, hidden holdout evaluation, multi-day monitoring or representative domain coverage is implied.
